# idchain-brasil

Plataforma acadêmica para integração entre certificados digitais ICP-Brasil, blockchain e smart contracts.

## Sobre o projeto

O IDChain Brasil tem como objetivo demonstrar como a assinatura digital ICP-Brasil pode ser integrada a uma rede blockchain para garantir autenticidade, integridade, rastreabilidade e auditabilidade de documentos eletrônicos.

A aplicação não armazena documentos completos na blockchain. O documento é armazenado externamente e somente o seu hash criptográfico é registrado no smart contract.

> Este projeto possui finalidade acadêmica. A validação da assinatura ICP-Brasil é simulada no protótipo.
